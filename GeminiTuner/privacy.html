GeminiTuner 개인정보 처리방침

최종 업데이트: 2026년 5월 23일

개요

GeminiTuner는 gemini.google.com 사용 시 토큰·예상 비용을 보여 주는 Chrome 확장 프로그램입니다. 별도 서버를 운영하지 않으며, 데이터는 사용자 브라우저에만 저장됩니다.

수집하는 데이터

개발자 서버로 개인정보를 전송·수집하지 않습니다.

  • 사용량·설정 (토큰, 예상 비용, 월 예산, 환율 등) — chrome.storage.local에만 저장
  • API 키 (선택): Google AI Studio API 키를 입력한 경우, 동일하게 로컬 저장만 하며 개발자에게 전송하지 않습니다
  • 패널 위치 등 UI 설정 — 로컬 저장

수집하지 않는 데이터

  • Gemini 대화 내용·프롬프트·응답을 개발자가 받지 않습니다
  • 제3자에게 판매·공유하지 않습니다

권한 (Chrome)

  • gemini.google.com — FinOps 패널 표시 및 사용량 추정
  • generativelanguage.googleapis.com — API 키 유효성 확인 (선택 입력 시)
  • aistudio.google.com — AI Studio 지출 페이지 동기화 (사용자가 해당 페이지를 열었을 때, 로그인 세션 기준)
  • storage — 로컬 설정·누적 사용량 저장
  • notifications — 예산 경고 알림
  • scripting — 페이지 훅 주입 (토큰 메타데이터·DOM 추정)

제3자 서비스

Google Gemini·AI Studio 이용 시 Google의 정책이 적용됩니다.
